# Data Science Assignment Project

This folder contains the coursework and analysis work for the Data Science assignment focused on the 2026 FIFA World Cup.

## Project Contents

- World_Cup_2026_Analysis.ipynb — main analysis notebook for the project
- Task 1/Task 1.ipynb
- Task 2/Task 2.ipynb
- Task 3/Task 3.ipynb
- Task 4/Task 4.ipynb

## Overview

The project explores football match statistics and data analysis techniques using World Cup 2026 tournament information. The work includes:

- reviewing match results and performance indicators
- working with tournament statistics
- analysing goals, cards, corners, xG, shots, and fouls
- visualising patterns and summaries from the dataset
- completing structured tasks across separate assignment notebooks

## Main Focus Areas

- Descriptive statistics
- Data cleaning and preparation
- Exploratory data analysis
- Football match metric analysis
- Interpretation of results and patterns

## Requirements

To run the notebooks in this project, you will need:

- Python 3.x
- Jupyter Notebook or VS Code Notebook support
- pandas
- matplotlib
- seaborn
- openpyxl

Install the required packages using:

```bash
pip install pandas matplotlib seaborn openpyxl jupyter
```

## How to Use

1. Open the project folder in VS Code or Jupyter Notebook.
2. Start with World_Cup_2026_Analysis.ipynb for the main analysis.
3. Open the task notebooks in order to complete the assignment activities.
4. Run each cell in sequence to load, process, and analyse the data.

## Notes

This assignment is designed for learning and applying practical data analysis methods to a real-world sports dataset. The notebooks and tasks may be used for reporting, summary statistics, and exploratory analysis.
